# 版式与输入

坐标基于1080×1440。

封面：小标题（42,33），右侧页码；原封面在（40,95）起的1000×562区域，保持比例、不裁掉人脸／文字。背景一句（66,706）；主题（59,813），字号89；强调句（81,1000），字号146。细线约y1190；副标题（65,1241），字号37；页脚（65,1350），字号25。

内页：小栏目（72,58），右侧页码；圈起编号（72,170）。标题两行（73,347）、（73,489），字号101；细线y648；解释句y730；主要内容y868、947；简图约y1100；行动提示y1268；页脚y1340。保留留白，不塞满。

JSON结构如下。图片路径相对JSON目录或为绝对路径。`cards` 数量由内容决定，支持任意非负数量：有 `cover` 且 `cards: []` 为单张封面；省略 `cover` 为纯内容卡；两者同时存在为封面＋内页。不能两者都为空。`footer`、`section_label` 可空。页码、图片数与预览拼图尺寸自动计算，不存在五张内页限制。脚本只负责排版，不替用户判断信息取舍。

```json
{
  "section_label": "职业成长 / AI 时代",
  "footer": "嘉宾姓名 × 采访者姓名",
  "cover": {
    "image": "original_cover.jpg",
    "eyebrow": "人物访谈 / 成长笔记",
    "context": "一句真实的背景信息",
    "title": "主题标题",
    "emphasis": "核心问题？",
    "subtitle": "与主线吻合的一句阅读收益"
  },
  "cards": [
    {
      "title": ["第一行短标题，", "第二行短标题。"],
      "intro": "一句话解释观点。",
      "body": ["第一行实质内容，", "第二行实质内容。"],
      "takeaway": "读完可以采取的一步行动。",
      "diagram": {"kind": "steps", "labels": ["步骤一", "步骤二", "步骤三"]}
    }
  ],
  "post": {
    "title": "唯一推荐的平台标题",
    "body": "正文第一段。\n\n正文第二段。",
    "hashtags": ["AI时代", "职业成长", "个人成长"]
  }
}
```

上面只展示一张兼容旧版卡片结构，`layout` 省略或为 `legacy` 均沿用定稿排版。

## 灵活内容页

新内容优先使用 `layout: "editorial"`，不必套用固定两句正文、固定图示或五个观点。标题为1～2个预先分行的短句（字符串按换行拆分，也可数组）；`blocks` 至少一项，每项 `text` 必须非空，`label` 可省略；`takeaway` 可省略。一个页面可讲一个复杂观点，也可合并紧密相关的短观点。

```json
{
  "section_label": "访谈笔记 / 职业价值",
  "cards": [
    {
      "layout": "editorial",
      "title": ["身价形成于", "能力与环境之间"],
      "blocks": [
        {"label": "观点", "text": "选择怎样的工作环境，会改变同一种能力可以创造的价值。"},
        {"label": "例子", "text": "在这里写源材料中的真实例子，保留必要条件，不虚构数字。"}
      ],
      "takeaway": "审视自己的能力在哪里最有用。"
    }
  ]
}
```

正文区为 x76～1004、y730～1230，按实际字形宽度自动换行，依次尝试42、40、38px，块之间留空。38px仍超出就报错，必须精简、调整分组或拆页，不能裁掉内容或偷偷缩成小字。标题与行动提示仍需写成短句；旧版 `intro`、`body`、`diagram` 不用于 editorial 页。所有页面在内存中验证完成后才写出，溢出不留下半套图片。输出目录必须为空。

输出 `01.png` 起的实际页数、动态 `preview.jpg`、仅含图片的 `images.zip` 和 `post.txt`；发布文案标签以空格分隔。示例是完整兼容测试，不是新素材的固定数量建议。

可选 `diagram`：
- `steps`：3个 `labels`，正文仍展示。
- `balance`：2个 `labels`，中间加号。
- `comparison`：2个 `values`、2个 `labels`、可选 `caption`；简图占中部，正文移到下方。
- `note`：一个 `caption`，在正文下加线、再放注解，匹配第5个观点页。
- 省略：只排正文和行动提示。

`references/example-content.json` 可验证并复现此次定稿，示例素材不用于新主题。示例含更新后已认可的平台标题，避免旧标题回退。

字体在 `assets/fonts`，保留许可证。默认不是Windows行楷，也不是圆萌字。`--font yahei` 只用于当次明确指令，不改全局偏好；未装微软雅黑时不能声称已使用它。
