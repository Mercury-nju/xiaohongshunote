# 小红书白底黑字六图模板

先看 `assets/reference.png` 和 `assets/approved/contact-sheet.jpg`，读取 `artifact-template.json`。参考用于复现视觉风格，不是新作品的内容来源。用户当次要求优先于默认模板。

## 视觉规则

- 六张 PNG，1080×1440、3:4：一张封面、五张观点卡片。
- 白底、近黑字 `#111111`、大留白、左对齐；少量细线、圈号和箭头组织信息。
- 默认使用包内霞鹜文楷 `assets/fonts/LXGWWenKai-Regular.ttf.xz`。完整字体以 XZ 无损压缩，脚本自动解压加载，不删字形。使用真实字体排文字，保持成熟、规整的钢笔字感；不用毛笔字、圆萌字、彩色贴纸或渐变。
- 封面上半部放当前视频／博客的原始封面画面，保持人物和原图信息，下半部放主题与简短问题／核心判断。不能把示例人物挪给新主题。缺少原封面时说明缺少素材。
- 钩子要与内容吻合，不能编造收入、收益、承诺或人物原话。平台标题与封面文字互补。
- 页脚只放来源人物或来源名；未知则留空，不默认加整理声明或个人署名。

## 内容规则

从材料中提取五个观点，每页包含两行短标题、一句解释、两行实质内容、可选简图和一句行动提示。保持原意，区分采访者、嘉宾与整理者观点。删去重复内容，避免靠缩小字体塞满页面。

直接给一个最推荐的平台标题，突出可信背景与读者收益；按平台当时的字数限制填写。除非用户要求，不提供多个标题让用户选择。`OpenAI工程师：拉开差距的5件事` 仅是案例标题。

正文用自然中文短段落，最后放一个互动问题并在适用时注明来源。准备约五到六个相关话题，ASCII 空格分隔，最后一个后也留空格。

## 生成

1. 获取当前材料和原封面；已有素材直接读取。此技能的渲染脚本不下载视频、不抓字幕、不调用模型 API。
2. 按 [输入说明](references/layout-and-input.md) 编写 UTF-8 JSON。`references/example-content.json` 仅用于测试已有案例。
3. 在有 Pillow 的 Python 环境运行：

   ```text
   python scripts/render_cards.py --spec /absolute/path/content.json --out /absolute/path/new-output-folder
   ```

   命令应从技能目录运行，或将脚本路径改为绝对路径。默认使用包内字体，跨平台可用。仅在明确要求微软雅黑且 Windows 已安装时传 `--font yahei`。
4. 输出目录必须为空。查看 `preview.jpg` 和原尺寸 `01.png`，核对缺字、溢出、顺序、图像比例、页脚和手机可读性。先调整断行，避免擅自重设计。
5. 交付 `01.png`–`06.png`、`images.zip` 和 `post.txt`，展示封面和六图预览。不要改包内参考素材。

## 可选：浏览器准备草稿

仅在用户要求上传且具备浏览器工具时执行；没有工具时交付本地文件即可。登录由用户本人完成，不索要密码或验证码。

默认上传图片、填写正文、核对顺序后停在草稿页，供用户审核和点击发布。模板本身不授予发布权限。

标签需逐个输入并选择名称准确匹配的话题候选，不是粘贴含 `#` 的文字就完成关联。检查各标签为独立话题且之间有空格，最后一个也留空格；避免选到名称相近的候选。只读 DOM 可辅助核对，勿直接修改页面内部数据。

完成后保留并显示编辑页面，使用浏览器工具的 `markHandoff()` 或等效机制避免标签页自动关闭。说明已准备草稿、尚未发布。

## 素材与许可

代码和技能说明的 MIT 许可不覆盖字体、访谈原图、品牌标识或第三方内容。字体许可证在 `assets/fonts/OFL.txt`。案例仅展示版式，复用新主题时替换为有权使用的素材。
