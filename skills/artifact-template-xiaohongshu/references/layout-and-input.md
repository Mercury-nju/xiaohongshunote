# 版式与输入

坐标基于1080×1440。

封面：小标题（42,33），右侧页码；原封面在（40,95）起的1000×562区域，保持比例、不裁掉人脸／文字。背景一句（66,706）；主题（59,813），字号89；强调句（81,1000），字号146。细线约y1190；副标题（65,1241），字号37；页脚（65,1350），字号25。

内页：小栏目（72,58），右侧页码；圈起编号（72,170）。标题两行（73,347）、（73,489），字号101；细线y648；解释句y730；主要内容y868、947；简图约y1100；行动提示y1268；页脚y1340。保留留白，不塞满。

JSON结构如下。图片路径相对JSON目录或为绝对路径。实际必须5张卡片，`footer`可空。预先按语义断行；脚本在安全字号内适配，仍放不下则报错。

```json
{
  "section_label": "职业成长 / AI 时代",
  "footer": "嘉宾姓名 × 采访者姓名",
  "cover": {
    "image": "original_cover.jpg",
    "eyebrow": "人物访谈 / 成长笔记",
    "context": "一句真实的背景信息",
    "title": "主题标题",
    "emphasis": "核心问题？",
    "subtitle": "五个思路，能帮助你做什么"
  },
  "cards": [
    {
      "title": ["第一行短标题，", "第二行短标题。"],
      "intro": "一句话解释观点。",
      "body": ["第一行实质内容，", "第二行实质内容。"],
      "takeaway": "读完可以采取的一步行动。",
      "diagram": {"kind": "steps", "labels": ["步骤一", "步骤二", "步骤三"]}
    }
  ],
  "post": {
    "title": "唯一推荐的平台标题",
    "body": "正文第一段。\n\n正文第二段。",
    "hashtags": ["AI时代", "职业成长", "个人成长"]
  }
}
```

上面只展示一张卡片结构；实际 `cards` 必须5项。

可选 `diagram`：
- `steps`：3个 `labels`，正文仍展示。
- `balance`：2个 `labels`，中间加号。
- `comparison`：2个 `values`、2个 `labels`、可选 `caption`；简图占中部，正文移到下方。
- `note`：一个 `caption`，在正文下加线、再放注解，匹配第5个观点页。
- 省略：只排正文和行动提示。

`references/example-content.json` 可验证并复现此次定稿，示例素材不用于新主题。示例含更新后已认可的平台标题，避免旧标题回退。

字体在 `assets/fonts`，保留许可证。默认不是Windows行楷，也不是圆萌字。`--font yahei` 只用于当次明确指令，不改全局偏好；未装微软雅黑时不能声称已使用它。
